🎯 Tujuan Pembelajaran
🏠
🧮

Siswa mampu mengenali komponen antarmuka aplikasi spreadsheet (sel, baris, kolom, dan sheet).

🔣

Siswa mampu menggunakan rumus dan fungsi dasar (SUM, AVERAGE, MAX, MIN, COUNT) untuk mengolah data.

🎨

Siswa mampu memformat dan menyusun data agar informasi mudah dibaca dan dianalisis.

📊

Siswa mampu membuat grafik (chart) sederhana untuk menampilkan data sesuai tujuan penyajian.

🔀

Siswa mampu mengurutkan (sort) dan menyaring (filter) data sesuai kebutuhan analisis.

💾

Siswa mampu menyimpan dan berbagi file spreadsheet dengan format yang tepat.

↩
📖 Materi Spreadsheet
🏠
🧮

Antarmuka Dasar

Cell (perpotongan kolom & baris), Sheet Tab untuk berpindah lembar kerja.

🔣

Rumus & Fungsi

Diawali tanda "="; contoh =SUM(), =AVERAGE(), =MAX(), =MIN(), =COUNT().

🎨

Format Data

Bold, warna, border, format angka/mata uang/tanggal agar data mudah dibaca.

📊

Grafik / Chart

Visualisasi data seperti bar, line, dan pie chart sesuai tujuan penyajian.

🔀

Sort & Filter

Mengurutkan (A-Z / Z-A) dan menyaring data sesuai kriteria tertentu.

💾

Simpan & Bagikan

Format .xlsx / .csv, ekspor PDF, dan berbagi file lewat penyimpanan cloud.
